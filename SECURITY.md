# Security

Please do not report vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting feature when it is available. Open the [GitHub repository](https://github.com/jomarmontuya/m3-expressive), then use the repository's **Security** tab to report the issue privately. If private reporting is unavailable, open a public issue that asks the maintainers for a private contact channel. Do not include vulnerability details in that issue.

Include the affected version, steps to reproduce, and the possible impact. GitHub will keep the report private while maintainers investigate.
